- Modes: 1 Vertices (corners), 2 Faces, 3 Object (whole model). Click selects, Shift+click adds, drag a box to box-select, A selects all, Alt+A deselects.
- G move, R rotate, S scale. While moving: X / Y / Z lock to an axis, type a number then Enter for an exact amount, hold Ctrl to snap, Enter or click confirms, Esc or right-click cancels.
- E extrude (pull a face out and build sides; then move it, e.g. E then 0.5 Enter). I inset (smaller face inside a face, leaving a border). D subdivide (split faces into smaller ones). F fill (in Vertices, Shift+click 3-4 corners in order, then F makes a face). M merge selected corners into one. X or Delete removes selection. Flip button turns a face inside-out.
- Paint: pick a color with the color button, select faces, press P.
- Mirror X toggle: model the right half, the left copies it.
- Camera: middle mouse (or Alt+left) orbit, Shift+middle pan, wheel zoom, Home frames the model, numpad 1 front, 3 side, 7 top.
- Ctrl+Z undo, Ctrl+Shift+Z redo, Ctrl+S save (also exports the .glb the game uses).
- New Shape menu: cube, cylinder, cone, sphere, plane. No bevel, loop cut, smooth shading, textures or animation yet (Blender is the free option for those).
